# 近大病院 院内ナビ（非公式）

近畿大学病院（大阪府堺市南区三原台1丁14番1号・近畿大学おおさかメディカルキャンパス、2025年11月開院）の院内を、
**「いまいる場所」と「行きたい場所」を選ぶだけ** で、通る階・乗るエレベーター・道順を表示する Web アプリです。

**公開URL:** https://mynrminto.github.io/kindai-hospital-navi/

## 使い方

1. 「いまいる場所」を選ぶ（駅から来た方は「駅からのデッキ入口」）
2. 「行きたい場所」を選ぶ（よく使う行き先はボタンでも選べます）
3. 階ごとの模式図と、手順リストで道順を確認
4. 車いす・ベビーカーの方は「エレベーターのみ」をオン

経路は URL で共有できます（例：`?from=deck&to=reception`、`&bf=1` でエレベーターのみ）。
受付や案内掲示に QR コードとして貼る使い方もできます。

## データの出典と推定部分

| 内容 | 根拠 |
|---|---|
| 各診療科・施設が **どの建物の何階にあるか** | 近畿大学病院 公式サイト [フロアマップ](https://www.med.kindai.ac.jp/floormap_facility.html)（2026年10月確認） |
| 駅からのデッキが3階で病院に接続、初診は2号館3階 総合受付 | 公式サイト [交通アクセス](https://www.med.kindai.ac.jp/traffic_access.html)・[受付時間・診療日](https://www.med.kindai.ac.jp/patients_visitors/hours_of_operation.html)、フロアマップの「デッキ連絡階 3F」表記 |
| デッキ沿いに外来棟（左）・管理棟（右） | 公開されている来院レポート記事 |
| **建物の配置・連絡通路の階・エレベーター/エスカレーターの位置・距離・所要時間** | **推定**（公開情報に記載がないため模式的に作成） |

推定部分はアプリ画面にも明記しています。実際の院内表示・スタッフの案内を優先してください。
誤りに気づいた方は Issue でお知らせください。

## 構成

静的サイト（HTML / CSS / JavaScript のみ、ビルド不要）。

- `data.js` … 建物・階・施設・通路データ（ここを直せば地図と経路が更新されます）
- `app.js` … 経路探索（ダイクストラ法）と描画
- `style.css` … スタイル（ライト/ダーク対応）
