# 近大病院 院内ナビ（非公式）

近畿大学病院（大阪府堺市南区三原台1丁14番1号・近畿大学おおさかメディカルキャンパス、2025年11月開院）の院内を、
**「いまいる場所」と「行きたい場所」を選ぶだけ** で、通る階・乗るエレベーター・道順を表示する Web アプリです。

**公開URL:** https://mynrminto.github.io/kindai-hospital-navi/

## 使い方

1. 「いまいる場所」を選ぶ（駅から来た方は「駅からのデッキ入口」）
2. 「行きたい場所」を選ぶ（よく使う行き先はボタンでも選べます）
3. 階ごとの地図と、手順リストで道順を確認
   - 行き先は「採血・検査」「会計」「トイレ」など **目的** からも選べます（いちばん近い場所へ案内）
   - 「地図をタップして現在地を選ぶ」で、地図上から現在地を指定できます
   - 「3Dマップ」で各階を積み重ねた立体表示に切り替え、階をまたぐ経路を確認できます
4. 車いす・ベビーカーの方は「エレベーターのみ」をオン

経路は URL で共有できます（例：`?from=deck&to=reception`、`&bf=1` でエレベーターのみ）。
受付や案内掲示に QR コードとして貼る使い方もできます。

## データの出典と推定部分

| 内容 | 根拠 |
|---|---|
| 地図（各階のフロアマップ画像 `maps/`） | 近畿大学病院 公式サイト [フロアマップ](https://www.med.kindai.ac.jp/floormap_facility.html)（2026年10月取得）。著作権は近畿大学病院に帰属 |
| 各診療科・施設・エレベーター・エスカレーター・廊下の位置 | 上記フロアマップ画像から読み取り |
| 駅デッキがつながる出入口（3階 中央出入口） | 公式 [交通アクセス](https://www.med.kindai.ac.jp/traffic_access.html) と来院レポート記事からの **推定** |
| 7〜10階の病棟フロア（`maps/floor07〜10.png`） | 院内図面をもとに公式マップと同じ見た目で作成した **簡略図**（`tools/make_ward_maps.js`）。病棟名・診療科・見舞客用EV（西EV/東EV）・トイレのみ掲載し、病床数・職員用設備は省略。7階は公式画像に病棟ラベルを追加 |
| 7号館（管理棟）の店舗への行き方 | 公式マップに7号館の図がないため **推定** |
| 所要時間・距離 | **推定**（画像1px≒0.12m、歩行0.9m/秒、EV待ち40秒） |

推定部分はアプリ画面にも明記しています。実際の院内表示・スタッフの案内を優先してください。

## 構成

静的サイト（HTML / CSS / JavaScript のみ、ビルド不要）。

- `maps/` … 公式フロアマップ画像
- `data.js` … 各階の通路ノード（画像のピクセル座標）・エレベーター・行き先データ
- `app.js` … 経路探索（ダイクストラ法）と描画
- `view3d.js` … 3D表示（`vendor/` の three.js r128 を使用、MITライセンス）
- `style.css` … スタイル（ライト/ダーク対応）
